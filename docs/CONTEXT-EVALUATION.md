# Coding 上下文策略验收

日期：2026-10-22。范围：项目实际安装的 pi SDK 1.3.0、真实文件工具、真实会话文件及回环 HTTP 模拟模型。此文记录工程行为，不是 SWE-bench、Terminal-Bench 或 LongMemEval 分数，不证明真实模型质量提升。

## 运行方式

在 `coding-agent` 目录使用 Node.js >= 22.19：

```sh
node --test test/memory-tasks.test.mjs
```

测试只访问 `127.0.0.1`，不读取生产凭据或调用付费模型。各测试使用独立临时目录，结束后清理。模拟器返回的 usage 是合成字符估计，不能记为供应商 Token，也不能用于费用节省宣传。

本轮首次直接调用 PATH 上的 Node v20.20.2，在模块加载阶段因 undici `markAsUncloneable` 缺失失败，未运行任务。随后显式使用符合要求的 Node 运行时，最终 16 项工程任务全部通过，运行约 8.0 秒。环境负例并非压缩策略失败；不能因此降低项目最低 Node 版本。

## 对照数据与负结果

`CODING_CONTEXT_POLICY=baseline` 是可信运行环境指定的原摘要策略对照；默认 `layered-v1`。用户提示词不能切换该开关。两组共享同一 SDK、回环模型行为、输出上限和升级后的工具实现，比较的是分层策略整体（含recall声明、容量预留与历史请求投影），不能把共同的工具分页升级算成此 A/B 独立测出的收益。

| 固定模拟场景 | baseline | layered-v1 |
|---|---:|---:|
| 短任务完整 HTTP 请求体字节 | 2,577 | 3,433 |
| 长任务最终原要求可见 | 否 | 是 |
| 长任务 SDK 压缩次数 | 2 | 3 |
| 长任务模型回环 HTTP 请求数（包括摘要） | 19 | 21 |
| 长任务请求体字节总和（包括摘要） | 159,681 | 165,700 |
| 真实供应商请求 | 0 | 0 |

必须保留的负结果：短任务增加 856 字节；长任务增加 2 次回环请求与 6,019 字节。在此场景下没有得到成本下降证据。计数为这次冻结模拟器的工程观察，并不是供应商 Token、美元费用或生产延迟。随机引用长度固定，但策略或测试夹具调整会改变数字，需重新记录，不能混用历史结果。

模拟摘要故意丢掉第一条要求；最终模拟器只检查传入上下文是否包含该要求，并通过真实 write 保存布尔结果。这证明该失败条件下的信息恢复和工具链路有效，不证明真实模型会正确理解要求、检索遗漏材料或完成更多开发任务。

补充负例：加入 M15 时首轮 15/16 通过。模拟器最初只识别 `<conversation>`，将 SDK 的 turn-prefix 摘要错当普通对话，导致“摘要试图调用工具”的真实 SDK 拒绝；未发生工具重放。已按官方摘要 system 消息统一识别普通摘要与前缀摘要，最终 16/16 通过。上表为修正夹具后的完整重跑，替代此前 12/14 项运行的字节数字。

## 限制与下一步

- 当前策略按原请求和时间顺序保留有限片段，没有独立语义提取、事实核验或自动冲突消解。长请求尾部可能不在片段中，需按引用回读完整原文。
- 上下文注入受字节上限控制。小窗口下不能同时保留所有历史要求；模型是否主动回读仍需真实质量测试。
- 回读存储有数量、单条和总量硬上限。达到配额时有界降级：发出 LIMITED、不生成虚假回读引用，原 SDK 会话仍保存用户请求；损坏仍拒绝读取。持久原文不等于跨项目或跨账号共享长期记忆。
- 本文件的任务集未跑公网真实模型、真实供应商或正式第三方 benchmark；上线健康检查另见私有部署验收，不是质量评测；未证明生产承载能力、费用降低或模型成功率提升。

后续真实模型对照应冻结能实际触发压缩的一小组开发任务，固定模型、工具、预算；同时记录代码测试结果、遗漏要求、请求数、供应商 usage、摘要/回读成本和耗时。未触发压缩的任务单列，未知费用明确为未知。每轮另设一次性标记、请求与费用上限，不重放历史付费探针。终端任务只在已验收隔离环境运行。
