# 本机目录项目（M032）

Coding Agent 的“选择项目 → 添加本机文件夹”使用浏览器 File System Access API，直接访问用户选择并授予读写权限的目录。不是上传 ZIP 或同步服务器副本。模型和 pi 仍在服务器运行，文件工具通过已登录会话的短期请求通道交给当前浏览器执行；被读取的内容及操作参数会发送到服务端和所选模型，并可能进入既有会话/上下文归档。目录句柄保存在此浏览器的 IndexedDB，按账号与项目绑定，不发送操作系统绝对路径。

## 使用

1. 桌面 Chrome/Edge 通过 HTTPS 打开 Coding Agent。
2. 打开“选择项目”，点击“添加本机文件夹”，在系统选择器中选择代码目录并允许读写；项目名称留空时使用目录名。
3. 输入任务。Agent 可以列目录、读取 UTF-8 文件、新建文件和精确替换文本。修改需批准，直接写回原目录。
4. 任务运行期间保持此页面打开。权限失效时点击“重新授权目录”；不同设备或没有保存句柄的浏览器需重新创建本机项目，不能凭同名目录冒充原项目。

不支持目录授权的浏览器仍能使用原有服务器项目。普通 HTTP 内网地址通常不能使用本机目录，使用 HTTPS 公网入口或 localhost。浏览器能力依据：[Chrome 官方 File System Access API 文档](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)。

## 边界

- 这是浏览器直接文件接入，不是桌面常驻执行器。关闭/刷新页面不会恢复原执行连接；待处理文件请求30秒超时并中止，已经完成的修改保留。先检查文件再发起新任务，禁止自动重放结果未知的写入。
- 本机终端、Git 命令、测试命令、删除/移动文件、二进制编辑、团队模式未开放。原服务器项目的团队执行保留。本机 auto 模式不会切换团队。
- 工具单文件上限64KiB UTF-8，列表最多1000项；文件面板递归最多10层/1000文件/3000条目。模型可以指定子目录逐层查看。
- 拒绝绝对路径、上级路径、Windows路径别名及 `.git`、`.ssh`、`.env*`、凭据类名称等保护路径。文件访问范围由浏览器授予的目录句柄限制，不接受客户端路径去打开服务器文件。
- 覆盖已有文件必须先读；写前及提交前比对已读内容，外部修改会报冲突。浏览器 writable 使用 exclusive 模式并在关闭前暂存写入；这不是操作系统级跨编辑器事务，无法承诺抵御外部程序在最终检查之后同时写文件。新文件创建之后失败可能留下空文件，错误不自动重试。
- 当前页面显示本轮本机文件差异；刷新后不保留这个差异缓存，请使用本机编辑器/Git审查。文件内容本身已写回磁盘。

## 执行契约

项目记录新增 `source=local|server`（缺省旧记录仍按 server）。本机 turn 必须携带仅当前页面持有的随机 `localClientId`；不持久化此连接标识供刷新恢复。Java 按账号/会话/当前轮次验证，操作只驻留活动执行状态，不从会话事件重放。GET pending → POST single claim → 浏览器执行 → POST idempotent result。结果确认失败时仅重发内存中已缓存结果，不重复文件操作；刷新丢失连接标识后拒绝领取旧请求。取消或重启撤销通道。

本机文件请求经原有审批与模型治理执行，shell强制关闭；服务端 `/file`、`/files`、`/diff` 拒绝本机项目，避免悄悄落到空服务器工作区。模型预检先完成浏览器 ping，再发真实模型请求。文件预览在任务运行中不更新 Agent 的已读版本基线。

## 验证入口

- `coding-agent/test/local-files.test.mjs`：审批先于文件请求、取消/超时、响应去重、分页、禁用服务器文件回退。
- `CodingLocalFilesTest`：来源/模式、账号/连接/轮次绑定、单次领取、结果幂等、取消及服务器文件接口拒绝。
- `CodingLocalFilesEndToEndTest`：实际 HTTP→Java→Node JSONL→pi→本地 SSE 模拟模型→文件操作回传；合成设备目录确实写入，服务器项目目录没有副本。浏览器端在该测试中由Java模拟。
- `tests/local-files.browser.mjs`：真实 Chrome FileSystemDirectoryHandle/OPFS 文件读写、IndexedDB恢复、审批前不写、外部冲突、刷新旧任务拒绝、路径保护、移动布局。原生系统选择器由返回合成OPFS句柄的测试替身代替，没有自动操作用户真实文件夹或原生权限对话框。

以上为离线工程验收，不是付费模型质量评测或原生桌面完整能力验收。CI已加入新测试，Git未推送时远端CI不会自动运行。


## 用本机 VS Code 看代码（M034，当前开发分支）

右上角“VS Code”首次填写所选文件夹的完整本机路径，保存后可直接打开整个目录；下拉按钮可修改或清除。浏览器无法自动取得或核对绝对路径，请确认与授权目录一致。路径只保存在当前浏览器，未发送到服务端。需要安装VS Code并允许浏览器打开外部应用。

VS Code保存后可在网页“项目文件”刷新。新增搜索、只看已改文件、复制预览内容、差异展开/收起和读取状态提示。服务端项目不会自动同步到本机，入口会说明这一边界。详见[M034实现与验收](M034-EDITOR-UX.md)。此文档更新不代表已发布上线。
