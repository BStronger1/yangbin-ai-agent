# Coding 项目长期记忆

2026-10-22，M029。该功能接入 Coding 项目；通用 Chat/Work、Manus 便签和伙伴偏好保留原机制，未自动统一或跨空间共享。

## 使用

在 Coding 中选择项目，打开「项目记忆」。保存事实、偏好或项目约束后，同一账号、同一项目的新会话会按任务相关性取回条目。名称用于区分事实；更正会增加版本，旧版本不再参与检索。归档暂时排除，恢复后可再次使用；忘记会清空普通记忆文件中的名称与正文，并保留不可直接阅读内容的哈希墓碑以阻止旧名称/旧值被自动重新加入。原始对话、备份及已发送给供应商的请求不会因此删除。

记忆设置可关闭检索，关闭不会删除已有条目。自动保存默认关闭；开启后只处理成功且未取消的任务中当前用户明确标注的行：

```text
偏好:回答语言=中文，先说明实际验证结果
项目约束:测试框架=沿用项目已有的 Vitest 目录结构
事实:服务区域=ap-southeast-1
```

每轮最多4条候选；冲突、敏感内容、已忘记名称/值不会自动覆盖人工修正。需要修改已有事实时请使用编辑。此处是可控规则提取，不是模型自动理解任意对话，无额外提取、向量或重排序付费请求。

## 实现和边界

| 层次 | 已有或新增能力 | 不应混淆的边界 |
|---|---|---|
| 上游 pi 1.3.0 | 持久会话、恢复、压缩、分支摘要 | 这些不等于本项目新增的跨会话事实生命周期 |
| 原项目接入 | pi Loop/会话恢复、M027需求摘录和同会话工具快照 recall；Manus手动便签、伙伴持久偏好 | 原 recall 只限当前会话；自定义资源加载器不自动加载上游默认 AGENTS 内容 |
| M029新增 | Coding账号/项目记忆API、管理界面、版本/归档/遗忘、当前用户结构化提取、请求时有界检索 | 未接入全部工作空间；非语义向量检索，非产品内部多Agent |

存储为 `tmp/coding/<owner>/projects/<project>/memory.json`，在模型工具工作区之外，随已有coding备份保留。账号身份来自服务端认证上下文，项目必须存在，来源会话和轮次须属于该项目。Java单实例同步写、临时文件原子替换、乐观版本与幂等请求编号防止覆盖；不是多实例共享文件系统并发数据库。每项目最多200条有效或归档条目、2000条含墓碑、5000写入回执；满额明确拒绝，不静默删除人工约束。

检索融合名称精确匹配、词项和中文双字片段，确定性排序，排除归档和墓碑。每次模型请求前重新读有效版本，注入仅为临时上下文，不写回pi原始历史或摘要。最多6条、2048字符且最多2048 UTF-8字节；实际字节预算不超过上下文窗口的四分之一，并计入额外压缩预留及逐请求模型准入。实验可通过可信运行环境进一步收窄，普通HTTP请求不能修改预算或评测策略。无相关证据时不注入。长条目可能因预算被跳过，不保证所有重要约束永久在上下文中。

记忆是低信任用户材料，不能授予工具权限、关闭审批或开放shell；runtime没有模型可调用的记忆写入工具。只有可信Java传入的账号/项目文件路径可读，路径与session/workspace绑定并拒绝符号链接。常见凭据模式会拒存，但模式过滤不是能识别一切秘密的DLP；凭据应继续保存在总设置的加密连接配置，不能放进记忆。

## 验证和评测

工程验收与模型质量分开。服务测试覆盖保存、去重、版本冲突、归档/忘记/旧名称不复活、敏感模式、隔离和中断；HTTP集成用本地供应商夹具检查真实pi请求正文；独立JVM测试检查跨进程恢复。

四组固定协议和限制见 [评测协议](../evaluation/memory-m029/README.md) 及 [独立离线验收](../evaluation/memory-m029/VALIDATION.md)。A为原生pi压缩、B仅M027、C仅新增长期记忆、D同时开启。自建Coding约束小样本不等于真实仓库开发或LongMemEval分数；没有充分数据前不宣称质量提升或省钱。
