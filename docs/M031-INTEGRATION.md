## 配置与兼容

Node 24.19.0 为本轮实际测试版本；Java 22.0.1、Maven 3.9.9；CI使用Java21与Node24.19.0，CI远程作业尚未运行。固定依赖见coding-agent/package-lock.json（pi1.3.0、MCP SDK2.3.1、A2A SDK1.3.0等）。原默认Node20不兼容，因此所有runtime测试显式指定Node24。

`CODING_MCP_CONFIG` / `app.coding.mcp-config`：服务器拥有的、位于工作区外的JSON，最大256KiB；`servers`按accountId/projectId过滤，`credentials`按resource/issuer及作用域匹配。令牌不写入仓库、模型上下文或日志。服务器结构与支持矩阵见 [MCP说明](M031-MCP.md)。

`CODING_A2A_CONFIG` / `app.coding.a2a-config`：同样只能来自可信服务器配置；`bindings`每个accountId/projectId至多一项，包含remoteId、HTTPS url/cardUrl、expectedCardHash、permissions（read/write子集）、reservedTokens（1–60000）、maxCostMicros（非负整数或null）、timeoutMs及受同账号/项目/remoteId/endpoint/权限/期限约束的credential。未配置或无当前作用域绑定时使用本地。无面向模型或普通HTTP请求的注册接口。用户审批能看到实际委派文本及Card/参数哈希；Card变化重新验证。远端总截止同时覆盖用户审批、Java许可和网络执行。

原记忆schema1兼容增量字段；旧格式已由M029测试及重启恢复测试覆盖。新团队记录与预算账本位于当前用户会话私有state中，恢复只读取事件/产物，不继续旧执行。产物API先认证会话与turn，再验证受控目录、链接、大小和SHA-256；前端仅安全文本预览/下载，不追随外部URL或渲染HTML。
