## 防重放与停止规则

每次真实运行必须绑定明确批准的最终 manifest、模型配置、源码、费率、数值预算和新的运行目录。先独占创建并 fsync RUN_STARTED；再为每实例独占创建 STARTED-{taskId}-{arm}.json；每请求发送前追加唯一 requestId 的 REQUEST_STARTED 及三层预留并 fsync。写入失败不得发送。已有标记即拒绝，COMPLETED 也不授予重跑权。超时、未知外部结果、已开始无结算请求或失败实例不能改目录再试；新实验需要新协议及批准。

verify.mjs 提供的 claimInstance 仅是离线独占标记原语演示，测试用合成临时目录；没有真实网络 runner。assertLiveLaunch 始终拒绝。不要把 marker 演示、文件 hash 核验或人写一个 approved=true 当成真实用户批准。

以下情况停止整个新批次：任一预算拒绝、墙钟截止、摘要 length/error、未知工具副作用、取消、账本失败、越权或凭据异常、冻结源码/配置变化。实际完成但答案错误只记录预注册 false，按固定次序继续，不补题。其余实例记 NOT_RUN_PRIOR_STOP，明确请求/已知消耗为 0，内容和安全评分为 null；不能把它们算成错误答案或安全通过。所有供应商自动重试关闭；输出上限和单例预算不自动扩大。

取消只证明主机停止等待/后续调度；外部执行器不响应取消时，副作用保持 UNKNOWN，迟到结果不能发表为已完成产物。
