# M031 UI：统一弹层、键盘与未保存保护

日期：2026-10-22。共同开发快照：`2f7a8d3`；本专项仅在 `m031/ui` 隔离工作树开发。未访问生产，未调用供应商模型，未修改路由、应用入口、依赖锁文件或后端审批权限。

## 审计问题与落地范围

| 界面 | 原问题 | 本次行为 |
|---|---|---|
| Coding 历史/项目/模型/审批策略 | 容器 ESC 同时清空四个开关，无层级/Tab/恢复 | 各层登记同一栈；ESC 一次关闭顶层；初始焦点、Tab/Shift+Tab 范围、恢复及显式关闭 |
| Coding 文件抽屉/编辑 | 编辑、关闭、切换项目/任务及离页可丢稿 | 编辑层优先关闭；未保存先确认；继续编辑默认，丢弃须显式选择；路由和 beforeunload 保护 |
| Coding 审批 | 原为持久内嵌卡片，无收起边界 | 收起仅隐藏详情，仍显示“查看待审批操作”；ESC 不调用批准、拒绝或停止 API |
| 项目记忆 | native cancel 直接卸载；忘记确认无独立层；409 清空更正草稿 | 父 dialog 与忘记确认各自登记；busy 拒绝关闭；409 保留草稿并禁旧版本再次提交，用户核对最新条目后合并 |
| 模型管理 | 局部焦点逻辑无统一层级，改字段即可静默关闭 | Teleport 到 body；删除确认独立层、默认焦点取消；关闭/切换模型须保护脏编辑 |
| 总设置 | 切换连接、离页与其他请求刷新列表可丢编辑/选择 | 连接切换及离页保护；保存连接/发现模型不清空未保存的模型勾选；手动添加失败保留输入 |
| 助手历史/转交/图片预览 | ESC、焦点、转交草稿规则不一致 | 复用同一栈；转交编辑有保护；关闭界面不提交任务 |

`src/composables/useOverlay.js` 使用一个 document 捕获监听与独立层栈，支持 Vue Teleport、原生 dialog 和局部面板。监听仅在有层时存在；卸载移除，忽略组合输入和长按重复 ESC，避免一次按键穿透多层。对 disabled fieldset 后代同样排除 Tab 导航。视觉容器 z-index 随打开顺序调整。模态层阻止焦点逃逸，非模态抽屉允许显式点击其他界面，Tab 保持当前层范围。

`useUnsavedChanges.js` 统一使用 native top-layer 确认，确认上的 ESC 等于继续编辑。busy 不进入丢弃流程；离页保护不写浏览器存储。卸载或账号变更取消仍待处理的确认，避免将旧账号的异步编辑动作继续应用。账号切换清空设置草稿与密钥。

Coding 的新执行方式选择为 auto/direct/react/plan/check/team，与 approvalMode 独立；默认 auto，沿 pending 请求冻结并在刷新重试中保留。团队选项注明服务端执行器前置。本专项仅验证字段传递，不证明后端 Loop/Teams 已可用。

## 复验

先安装前端已有锁定依赖（不要在只读依赖 junction 上运行安装），再执行：

```sh
npm run build
node tests/overlays.browser.mjs
node tests/memory.browser.mjs
node tests/model-profiles.browser.mjs
node tests/workspaces.browser.mjs
```

可设置 `CHROME_EXECUTABLE_PATH` 为已安装 Chrome，`EVIDENCE_DIR` 为每套件独立输出目录。本轮使用只读原前端 node_modules junction，只调用构建和测试，没有修改依赖。

## 明确边界

- 组合输入通过真实浏览器内合成 composition/keydown 事件验收；未做操作系统输入法、屏幕阅读器、Safari 或 Firefox 人工验收。
- 浏览器关闭保护测试覆盖事件处理；浏览器何时显示原生离页提示仍取决于用户交互策略。
- 账号/项目服务端鉴权、真实模型质量、后台取消、Loop/Teams 执行由集成专项独立验收。
- 不把关闭层等同取消工具、不自动重放未知结果请求、不自动保存密钥或记忆草稿。
