# M036：本机项目执行与 Coding 模型预算

日期：2026-10-29。源码基线：040a101d，独立分支 `m036/local-run`。

## 问题与修复

此前游戏任务仅调用 list；父目录被正确拒绝后，模型第二轮在输出 4096 Token（全部为推理）处截断，没有生成文件，旧运行时却报告成功。M035 已增加完成状态守卫；M036 继续解决预算与真实执行能力。

- Java 原来沿用聊天的 4096 输出额度；Node 还通过 outputReserve 再限制到最多 8192。现在 Coding 使用独立额度，默认服务上限 65536；明确配置与账号收紧策略仍优先。
- DeepSeek V4 / V4.1 别名支持 1000000 上下文，按模型输出额度预留压缩空间；不再用固定 8192 截断。独立 Node 模型默认参考官方 256000，服务端默认 65536，可配置至 384000。上下文、单次输出、整轮请求预算和账号日额度分别处理，页面展示实际生效数值。
- 通过 OpenAI 兼容网关选择 DeepSeek V4.1 时，也正确识别 reasoning_content 回传与原生思考强度。默认不强行改变供应商思考模式；用户显式选 high 等值时发送原生参数。
- 自动任务识别加入“制作、启动、运行、游戏”，避免制作任务进入不带工具的直接回答。
- 本机握手可注册 start / preview / process_status / stop。启动返回进程标识，后续查看实际退出码、输出或预览地址；完成状态仍必须有正常终止的可见答复。
- 包含 M034 的 VS Code 入口、文件审阅体验及 10 月 27 日已上线的加载与 PPT 恢复补丁。

## 本机运行器

网页提供下载包，解压后运行 `start.cmd` 或 `node start.mjs`，需要 Node.js 22 以上。输入项目目录，打开输出的配对链接。连接码在 URL fragment 中传入并立即从浏览器地址历史移除，不发给网站服务器、不写浏览器持久存储。也可手工输入地址和连接码。

运行器只监听 127.0.0.1，检查精确 Host、应用 Origin 和随机连接码；配对通过随机临时文件证明浏览器目录句柄与运行器指向同一实际目录。临时证明用后删除。浏览器可能要求本地网络访问授权。

命令使用本机用户权限，工作目录是已配对项目，**不是操作系统隔离环境**；每条启动命令均经过现有审批。允许的命令本身可能访问项目之外，因此不能把文件工具的路径保护等同于 shell 隔离。服务器既有 Linux 终端开关保持关闭。运行器不接收模型 API 密钥。

请求 ID 防止连接重试重复启动；断线或未知结果不自动重放。命令输出保留有界尾部；最多 4 个运行进程。静态预览限制为项目内允许的资源类型，拒绝受保护文件和链接路径。网页提供运行状态、预览链接与停止按钮。

## 本轮验证与失败保留

真实 DeepSeek V4.1 在用户指定本机目录生成 HTML / CSS / JavaScript 游戏，后续真实工具验证语法退出码 0，并启动可访问的 HTTP 预览。浏览器验证开始、键盘及动画、暂停继续、实际计分、碰撞结束、重新开始、触屏启动及手机布局，无页面异常。

独立验收共有 20 次已确认模型请求，输入 401158、输出 37562、总 438720 Token；费用 UNKNOWN。其中生成阶段一次输出 27154，超过旧 4096 限制。第一阶段因验收驱动重复分页和其额外请求上限中断，保留失败；修正驱动后核验已有文件，8 次调用正常结束，不重写游戏。更早两个准备失败均在接触供应商之前（目录缺失、远端缺少 Python 加密依赖），也保留证据。此数据不是 M033 benchmark 成绩。

发布运行时的服务器完整测试：174 项，173 通过、1 项 Linux 隔离环境不可用而跳过、0 失败。原 Linux 终端关闭保持。另有真实 Java→Node→SDK→本机文件 RPC 测试、账号额度测试及浏览器回归；初次小窗口兼容失败、错误测试 Node 路径、未授本地网络权限的失败均保留，修正后定向复验通过。

独立运行器浏览器检查 5 项、本机文件界面 30 项、编辑器体验 25 项、启动 4 项、游戏交互 11 项通过。浏览器测试的目录选择入口使用受控替代，不能据此宣称原生系统目录对话框全覆盖。

站点所有者长任务日额度支持独立配置 `app.coding.admin-daily-tokens`，默认不启用；本次发布已配置为 2000000。其他账号默认日额度、并发限制和显式收紧文件保持。
