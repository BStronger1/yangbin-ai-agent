# M042 桌面 0.2.1 与网站下载入口

2026-10-31。Windows x64 客户端升级到 0.2.1。登录页与工作台侧栏新增“下载客户端”，公开 `/download` 页面显示版本、大小、校验值与手动升级步骤。桌面应用菜单新增“关于”和“检查更新 / 下载客户端”。

下载文件放在独立持久目录 `downloads/`，由固定 `desktop.json` 发布清单指定唯一版本文件；接口拒绝目录遍历、其他文件与链接，支持 HEAD 与 Range。缺少有效文件或元数据时显示重试，不生成虚假下载链接。发布时先完整上传 ZIP、核对 SHA-256，再原子替换清单。前端更新不会删除安装包。

桌面版本读取统一 package.json；保留应用名和用户数据位置，原账号会话和本机目录绑定沿用。包内带现有文件工具依赖。桌面依然是未签名的 Windows x64 便携版，无自动安装更新；项目自身的开发环境需要安装。0.2.1 没有新增本机持久化工具日志，不能把 M041 服务端崩溃恢复保证外推到本机。
