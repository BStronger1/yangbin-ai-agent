# MCP 工具工作台

从侧栏「MCP 工具」或 `/mcp` 进入。此页操作已经由部署维护者配置的 MCP 服务，不在网页执行安装命令或新增任意远程服务器。

## 使用流程

1. 刷新工具目录，按名称或说明搜索。发现工具只说明取得了目录，不等于服务当前健康。
2. 选择时间、共享文档列表或共享文档读取工具。简单参数以表单填写，也可切换 JSON；复杂参数使用 JSON。读取文档前，先运行文档列表工具取得准确文件名。
3. 点击「运行工具」发起一次明确调用。页面显示实际返回内容、状态、耗时、调用时间和是否截断；失败不会自动重试。
4. 下载包含工具名称、调用编号、时间、参数和结果的 Markdown，或选择一位工作伙伴并点击「引用到伙伴」。结果保存为当前账号的附件，进入伙伴后先确认需求，再发送给模型。

MCP 的内置文档来自服务端**共享资料目录**，与用户在「个人知识库」上传的资料不同。需要检索自己的资料时使用知识库入口。工具结果作为数据使用，不应当作新的系统指令。

## 调用与历史

- 手动调用开放范围为当前已配置服务的 `currentTime`、`listKnowledgeDocuments`、`readKnowledgeDocument`；其他已发现工具仅展示，不通过此页执行。不会调用搜索付费服务或终端命令。
- 后端校验 JSON 对象、必填字段、未知字段和类型；支持有限的对象/数组/字符串/数值/布尔值、枚举和长度/数值边界。引用或组合 schema 不在当前支持范围。总参数最多 8000 字符，嵌套最多 8 层、数组最多 100 项；时间工具另检查 IANA 时区。
- 每个账号最多 1 个进行中的手动调用；全局执行线程 2、队列 4。默认最多等待 30 秒，可用 `app.mcp.manual-timeout-ms` 配置。超时或中断表示远端完成情况未知，取消等待不保证远端停止。
- 请求编号绑定账号、工具名和参数。网络状态未确认时，「确认同一调用」复用编号；记录仍在保留期内就不会再次调用。改变参数必须发起新编号。
- 按账号保存最近 50 条记录到 `tmp/work/<owner>/mcp/`。服务重启将未完成记录标为 `INTERRUPTED`，不会自动重放。结果保存最多 16000 字符，超出明确标注截断。
- 可清空当前账号历史；进行中的调用完成前不能清空。清空后旧编号不再具备去重记录。已导出文件或已交给伙伴的附件不会被清空历史操作删除。
- 伙伴引用仅允许成功结果，并检查当前账号和伙伴权限；同一记录引用到同一伙伴不创建重复附件。若该附件已绑定历史任务，将回到对应任务。用户可在伙伴任务中继续修改或删除资源。

## 接口

| 方法与路径（相对 `/api`） | 功能 |
| --- | --- |
| `GET /ai/mcp` | 工具、参数定义、发现状态与等待上限 |
| `POST /ai/mcp/call` | `{name, arguments, requestId}`；旧客户端可省略编号 |
| `GET /ai/mcp/history` | 当前账号的最近记录 |
| `GET /ai/mcp/history/{id}` | 查询同一调用状态 |
| `GET /ai/mcp/history/{id}/download` | 下载工具结果与来源 |
| `DELETE /ai/mcp/history` | 清空当前账号的已完成记录 |
| `POST /ai/mcp/history/{id}/attach` | `{partnerId}`；保存为伙伴材料 |

写接口由既有登录与 CSRF 网关保护；身份来自服务端已验证上下文。记录不跨账号读取。MCP 页面不显示部署连接凭据。

## 与智能体的关系

Manus 保留其原有 MCP 工具调用链路；聊天中的自动调用记录仍在聊天页。工作伙伴现在支持**用户显式引用已执行的 MCP 结果**，不会自主搜索并执行 MCP 工具。pi Coding Agent 的 MCP 接入、动态服务器安装、OAuth、跨服务资源/提示模板管理不属于本次已实现能力。

自动化验证包括 `McpWorkbenchTest`（参数、持久历史、幂等、超时、隔离与交接）、`EnabledFeaturesTest`（真实本机 MCP 服务及 HTTP 下载/交接），以及 `node tests/mcp.browser.mjs`。模拟模型和本机服务测试不代表所有第三方 MCP 服务兼容或模型内容准确。
