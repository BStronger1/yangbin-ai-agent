# 工作伙伴能力

11 个伙伴覆盖办公提效、内容创作、营销销售、电商运营、产品研发、数据分析、学习教育、求职成长、生活出行 9 个领域，共 42 项技能（40 文字任务、2 实时出行规划）。伙伴共享个人模型选择、连续任务对话、材料读取和真实文件交付；各自提供对应领域的任务工具箱。入口为侧栏「插件 · 技能 · 伙伴」，选择伙伴即可开始。

## 从技能到任务

在技能广场点击「使用技能」，直接进入对应伙伴并预选技能，可选择个人模型、上传文件、执行后继续修改。点击「填写需求」按目标、已有材料和约束填写；未知项可以留空。填写内容先进入输入框，用户检查后才发送。切换技能保留已输入草稿。每项文字技能有对应的交付核对标准，由后端随当前轮次指令冻结；这些是模型自检要求，不代表独立事实核验。

出行的城市规划/雨天安排仍进入有天气和地点依据的 `/tasks`；出行准备伙伴只整理已提供的材料，不自动查询实时价格、签证或班次。演示伙伴提供「快速制作 PPTX」旧入口与独立 NarrativePPT 工作台，伙伴文字对话不会直接创建演示项目。

这些工具箱使用冻结的领域指引和当前模型完成任务，效果取决于模型及材料；任务执行记录不等于内容事实全部核实。

## 模型和对话

- 输入框可选择 Claude / OpenAI / DeepSeek / Kimi / 自定义兼容模型，并通过「模型设置」保存自己的 Base URL、模型 ID 和 API Key。配置与选择按账号隔离，选择按伙伴记忆。
- 每轮保存不含密钥的模型快照；修改或删除模型配置不会改写历史。重复提交相同消息不重复调用模型；更换模型需发起新消息。
- 默认「自由对话」，按本轮要求回答；点任务卡片或技能菜单才选择模板。本轮明确的语言、篇幅、格式及局部修改要求优先于技能模板和保存偏好。
- 原 `/work/:skillId` 单次技能任务和独立 NarrativePPT 工作台有各自的模型配置；伙伴对话中的选择不会自动迁移这些旧入口。

## 输入和交付

每轮最多 3 个附件，每文件不超过 1 MiB：CSV、XLSX、TXT、MD、DOCX、文字 PDF、PNG、JPG。文字 PDF 最多 30 页，DOCX/PDF 最多提取 12 万字符；每文档最多向模型提供前 12,000 字符，整轮材料最多 24,000 字符，截断会明确标记。扫描件 OCR、图片视觉识别尚未接入，图片仅保存与预览。

成功回复生成 Markdown 与可编辑 DOCX。规范 Markdown 表格还会生成方案 Excel，最多 6 张表；所有单元格按文本保存，不执行模型生成的公式。方案表格标为待核对建议。

上传 CSV/XLSX 时，程序对完整接收的有界数据表计算数值个数、合计、平均、最小、最大、各列空白数和完全重复行数；模型接收统计与前 20 行预览。另交付包含原始数据及重算统计公式的 Excel，以及首个数值列的有界柱状预览。日期、百分号、千分位文本不自动变成数值；统计结果不证明因果。XLSX 输入公式只读取缓存。

可从「添加 → 引用任务资源」选择同任务的上传文件或生成文稿继续修改；不能引用其他账号、伙伴或任务的文件。任务资源合计限制为 200 个 / 30 MiB，上传和新生成文件均计入。任务页可确认删除当前任务及其资源，运行中的任务需先停止；删除后旧任务编号不能复用。

## 引用 MCP 工具结果

在 [MCP 工作台](MCP-WORKBENCH.md) 手动运行只读工具后，可以将成功结果保存为指定伙伴的附件，页面自动带入材料但不自动发送。附件包含工具名、参数、调用时间和原始结果；同一结果重复引用不会生成重复附件。MCP 共享文档不同于个人上传知识库。伙伴仍不会自主调用 MCP。

## 能力边界与验证

- 不会自动发送邮件、投放广告、生成视频、联网检索或执行任意代码；不会将文本建议标记为实际执行成功。
- RAG、MCP、`@伙伴` 派发、自动化和长期记忆尚未自动接入伙伴对话。
- NarrativePPT 的页面编辑、配图及 PPTX 导出需要独立服务，其模型设置与对话分开。
- 自动化回归使用模拟模型和本机 HTTP 服务，覆盖 11 个伙伴和全部 40 项文字技能、真实 DOCX/XLSX/PDF 文件、BYOK、账号隔离、重复请求、删除及浏览器交互；不代表已逐家验证付费模型的业务质量。

后端检查：`PartnerCapabilitiesTest`、`PartnerChatServiceTest`、`PartnerWorkspaceTest`、`ModelProfilesHttpEndToEndTest`。前端在构建后运行 `node tests/partners.browser.mjs`；CI 同步执行并保存报告。
