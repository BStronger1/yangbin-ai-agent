# 伙伴连续对话与个性化偏好（M013）

2026-10-17。用户希望伙伴像个性化智能体一样持续交流。本增量沿用 M012 的伙伴主页、已召唤切换、详情与授权，新增独立多轮聊天与显式个人偏好。HEAD f66db28，工作区累计修改，未提交或推送。

## 使用

- 在 `/skills?tab=partners` 召唤伙伴，进入 `/partners/:id`，输入消息并发送。可继续追问、补充文字材料、要求修改上轮内容；回复可下载为 Markdown。
- “新对话”不带入其他会话；“历史对话”可恢复同一伙伴的旧会话。URL 的 conversation 参数可直接回到该会话。
- “设置我的偏好”进入详情 → 指令 → 用户档案，可填写工作背景、表达风格与输出格式。最多2000字，仅当前账号/伙伴生效，清空保存即可移除；下一轮采用新版本，已有快照保留。
- NarrativePPT 伙伴同样能对话讨论需求，并保留独立工作台。聊天不直接读取或修改PPT项目，偏好不自动同步到PPT工作台。
- 已限制的伙伴仍可查看既有聊天，服务端拒绝新消息；旧版任务与文稿仍在折叠入口中。

## 数据与行为

`PartnerChatService` / `PartnerChatController` 提供 `/ai/work/partners/{id}/profile`、`/conversations`、`/conversations/{uuid}` 和 `/messages`。前端 `PartnerChat.vue` 调用现有认证与CSRF客户端。

- 会话保存在 `tmp/work/<owner>/conversations/<uuid>.json`，偏好在 `partner-profile-<id>.json`，随现有发布备份递归保存。
- 每轮冻结系统指令、偏好版本、历史轮次ID与执行指纹。模型收到 System + User/Assistant 完整配对的历史 + 本条 User；最近最多10轮成功记录，历史字符预算60000。失败/中断轮不加入后续上下文。
- 每账号最多100个会话，每会话最多100轮，每条输入12000字符、回复40000字符。单实例JSON存储；暂无归档、删除会话、流式回复、服务端取消或独立硬超时。
- 调用前原子保存 RUNNING，消息UUID同内容复用，revision控制并发，同会话只允许一条运行中消息。服务重建将RUNNING改为INTERRUPTED，不在业务层自动重新执行。SDK/供应商内部重试未另行计量。
- 网络不确定时先GET确认，浏览器sessionStorage保留待确认消息ID；需要用户主动“重试同一条消息”，继续用同一ID。切换账号/伙伴/会话清空界面并丢弃迟到响应，不自动再次POST。
- 当前是带角色指令、显式偏好和有限历史的文字伙伴；未自动学习跨会话记忆，未自动接入RAG/MCP、文件上传或任意工具执行，不是多Agent协作。
