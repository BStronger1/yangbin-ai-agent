# 伙伴任务与资源工作区（M014）

用户参考豆包图一至图三，要求独立伙伴首页、历史任务/资源、固定底部输入框和向上加载历史。本轮保留原侧栏与品牌，重构伙伴页面。

## 页面与交互

- 首页显示伙伴身份、已召唤伙伴切换、伙伴详情、一个新任务输入框；下方任务/自动化/资源标签。自动化尚未接入，明确显示状态。
- 点击任务或资源的来源任务进入独立对话页。顶部面包屑与任务切换，消息区占剩余高度，底部输入框固定174px（手机148px）。聊天内容仅一个纵向滚动区域；长Markdown回复不会扩大页面或推走输入框。
- 首次加载最近8轮，向上加载更早8轮并恢复阅读位置；阅读旧消息期间不自动拉回底部。提供回到最新消息按钮。历史内容分页，不是逐Token输出。
- Markdown经DOMPurify清理后排版；外部图片/iframe不由回复HTML加载。文件卡片、图表预览与资源下载均走账号认证。
- 加号菜单支持上传材料、本轮文字技能选择；连接器当前仅说明独立入口，不伪装已自动接入。停止任务会阻止后续发布，已发出的模型请求可能继续消耗服务商资源。

## 文件和真实处理边界

- 支持CSV/XLSX/TXT/MD/PNG/JPG；每次最多3个不同附件，每文件1MB。上传时按当前伙伴既有资源检查200个/30MB，生成产物未计入硬配额预留。
- CSV或Excel每表最多2000行、30列、每格2000字符；每Excel最多3表，一轮最多6表。首行为列名，仅有限十进制数进入描述统计。日期、百分号、格式化千分位不自动识别为数值。XLSX输入公式仅取缓存，不运行宏或输入公式。
- 根据材料执行COUNT/SUM/AVERAGE/MIN/MAX。模型接收计算结果和前20行预览，材料上下文截断24000字符；不是全量数据推理或因果分析。
- 每次成功回复生成Markdown；有表格时额外生成含说明、数值统计和原始数据的XLSX，统计公式经POI重算；第一张表存在数值列时生成首个数值列最多30个数值记录的PNG柱状预览。
- 图片可上传、保存和预览；本轮不做图片视觉识别或AI绘图。NarrativePPT继续保留独立制作工作台；未实现跨伙伴@派发队列、任意代码执行或自动组合MCP/RAG。
- 文件保存于tmp/work/<owner>/resources/<partner>，会话关联资源元数据与真实执行事件。旧会话不迁移重写；成功旧回复通过只读虚拟Markdown资源兼容下载。
- 新任务接口异步202，2个工作线程/8个排队位置，客户端每1.5秒查询进度；沿用消息幂等、版本校验、账号/伙伴隔离和重启中断保护。不自动重试未知结果。模型与历史上下文上限沿用M013。
